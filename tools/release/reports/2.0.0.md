This is the maintainer-facing summary, not a claim that every supported hardware
combination was tested. The release has not been published by the validation agent.
The remaining manual decisions are at the end of this report.

## Acceptance scope

The maintainer selected framework correctness, installation, documentation,
learning/STDP, full MaxFormer and CLIF training, real-input performance, Qwen quick
conversion and selected distributed/extras checks. This first campaign establishes
an internal baseline: previous-release comparisons were waived. Full training is
report-only, with no accuracy threshold and no requirement to match paper scores.

| Check | Result and boundary |
| --- | --- |
| Minimum CPU | Python 3.11 / Torch 2.6: 1822 passed, 1480 skipped, 60 FP8 cases deselected |
| Main CPU | Torch 2.7.1: 1822 passed, 1480 skipped, 60 deselected |
| CUDA | RTX 5090 / Torch 2.7.1+cu128 / Triton 3.3.1: 3304 passed, 6 skipped; five supplemented at the tested SHA; one native cross-device case reused from byte-identical implementation/test files |
| Installation | Pure wheel/sdist outside-source training, reset and checkpoint checks passed; native built from sdist and exercised on the GPU environment |
| Cleanup regression | GPU: 210 passed, one native skip; minimum CPU: 83 passed, 46 hardware skips; final PP4 rerun passed with four rank memory records |
| Cleanup performance | Three paired CLIF runs: median throughput ratio 0.99968, within the existing 2% gate; no speedup claim |
| Documentation | aab05038 CI, Changelog, strict Sphinx, formatting, lint and local links passed; no claim of all external URLs being reachable |
| STDP | Three-seed CLI replay: 90.63%, 89.98%, 90.06%; frozen-weight controls: 84.01%, 83.20%, 84.06%; 112 nearby CUDA rule/state/hook tests passed |
| Qwen quick | 0.5B BF16, T160, 16 levels, q0.999: PPL 9.4380585 to 10.1470017, +7.5115%, below the predeclared 15% limit; bounded quick evaluation only |
| Distributed | TP2, DDP resume and PP4 lifecycle/output checks; selected MCore TP2/PP2/PP4 and SGLang TP1/TP2 functional evidence |

The original CUDA report retains its blocked status; supplemental evidence closes
its required cases in the reviewed summary. A skip is not itself a pass.
Tempotron is covered by framework correctness tests; a separate complete retraining
or performance gate was not part of the final selected scope.

## Training and performance

| Task | Completed budget | Final top1 / top5 | Execution |
| --- | --- | --- | --- |
| MaxFormer / CIFAR-100 | 410 epochs | 81.37% / 94.04% | Frozen e892a445; AMP neuron path uses Torch CUDA eager FP16 |
| CLIF / Tiny ImageNet | 300 epochs | 63.48% / 84.24% | Epochs 1–111 Torch, 112–300 explicit Triton at b30bc885; optimizer/scaler/RNG resumed |

CLIF best top1 was 64.02% at epoch 293; it does not replace the final metric.
The final checkpoint's complete 10,000-image evaluation gave exactly equal
Torch/Triton loss, top1 and top5. These are single-seed long runs, not an estimate
of training variance and not all-Triton training from initialization.

RTX 5090 measurements use final weights and real inputs, three independent runs
per case, 20 warmup and 100 measured steps. Latency is the median of per-run GPU
median latency; throughput uses runner wall time. Training includes optimizer and
reset; data loading/augmentation is excluded. Raw reports also retain reserved
memory and sample variation; allocated memory alone is not total GPU demand.

| Workload | ms/batch | samples/s | Peak allocated GiB |
| --- | ---: | ---: | ---: |
| MaxFormer B64 inference, FP16 Torch neurons | 16.936 | 3774.7 | 0.816 |
| MaxFormer B64 training, FP16 Torch neurons | 43.550 | 1469.0 | 4.321 |
| CLIF B64 inference, auto Triton FP32 | 27.643 | 2312.8 | 0.958 |
| CLIF B64 training, auto Torch FP16 | 63.314 | 1010.5 | 6.384 |
| CLIF B256 inference, auto Triton FP32 | 134.091 | 1908.1 | 3.618 |
| CLIF B256 training, Torch FP16 | 297.244 | 861.2 | 24.965 |
| CLIF B256 training, Triton FP16 | 252.823 | 1012.5 | 19.248 |

The paired B256 provider comparison passed correctness checks and measured
17.6% higher throughput and about 22.9% less allocated memory. Smaller-batch
Triton training was slower; auto training remains Torch. This is not a general
cross-hardware or cross-version speedup claim.

## Review map and remaining manual decisions

The agent checked CLIF reference/kernel/autograd boundaries, learner reward timing
and hook lifecycle, Tempotron's public event/gradient contract and nearby tests,
PP4 output/reset checks, benchmark correctness/restoration, package provenance,
tutorial P1 corrections and artifact hashes. The review fixed a runner failure:
an installed distribution without Name/Version metadata now produces a recorded
error instead of an uncaught AttributeError. Invalid metadata is not ignored.
